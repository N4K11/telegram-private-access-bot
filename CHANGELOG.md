# Changelog

## 0.2.0 - 2026-04-28

- implemented Russian user and admin navigation;
- added channel and tariff admin management;
- added Telegram Stars invoice flow and idempotent payment processing;
- added invite issuance and subscription extension logic;
- added expiration worker with revoke flow;
- added admin analytics and user management tools;
- added broadcast campaigns and sender worker;
- added managed text templates with mojibake protection;
- added manual and scheduled backups with retention and admin delivery;
- added optional Crypto Pay invoices, webhook processor and reconciliation worker;
- added healthcheck, structured JSON logs and anti-spam/rate-limit middleware;
- updated Docker Compose, documentation, Makefile and deployment artifacts.

- created the initial project skeleton;

- added async SQLAlchemy models and repositories;
- added Alembic bootstrap and initial migration;
- added Dockerfile, docker-compose and environment template;
- added baseline tests and documentation skeleton.
