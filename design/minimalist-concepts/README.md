# Minimalist Bot Concepts

Набор минималистичных SVG-концептов для:

- аватарки бота;
- главного меню;
- профиля пользователя;
- покупки тарифа;
- поддержки;
- экрана "Получить ссылку".

## Арт-дирекшн

- Светлый фон с мягкими оттенками `sage / mint / sky`.
- Простые геометрические формы, тонкие линии и много воздуха.
- Один акцентный цвет на экран, без тяжелых градиентов и перегруженных деталей.
- Подходит для Telegram-бота, где картинка должна быстро считываться даже в маленьком размере.

## Файлы

- `avatar-concept-01.svg` — рекомендованный базовый вариант: доступ + навигация.
- `avatar-concept-02.svg` — монограмма `P`, более брендовый и нейтральный вариант.
- `avatar-concept-03.svg` — доступ через link/keyhole, более технологичный вариант.
- `menu-main.svg` — главное меню.
- `menu-profile.svg` — профиль пользователя.
- `menu-tariff.svg` — покупка тарифа.
- `menu-support.svg` — поддержка.
- `menu-link.svg` — получение ссылки.
- `preview.html` — локальный просмотр всей серии.

## Примечание

SVG можно:

- сразу использовать как концепт;
- открыть в браузере;
- экспортировать в PNG/WebP для Telegram;
- доработать под точный бренд-нейм и финальную палитру.
